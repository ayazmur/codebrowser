# Mini Web Browser

Мини-браузер, который запускается в GitHub Codespaces. Откройте его в браузере и используйте для навигации по любым сайтам.

## Возможности

* Адресная строка для ввода URL
* Кнопки навигации (назад, вперёд, обновить)
* Отображение веб-страниц через iframe
* Проксирование запросов для обхода CORS
* Тёмная тема, адаптивный дизайн

## Быстрый запуск в GitHub Codespaces

1. Откройте репозиторий на GitHub
2. Нажмите **Code** → **Codespaces** → **New codespace**
3. Дождитесь запуска контейнера
4. Откройте терминал и выполните:

```bash
python start.py
```

5. Нажмите на ссылку порта 8000 в панели Ports

## Локальный запуск

```bash
pip install -r requirements.txt
python start.py
```

Открыть `http://127.0.0.1:8000`.

## Ограничения

* Некоторые сайты (Google, YouTube, Gmail) блокируют отображение в iframe
* Для этих сайтов работает режим проксирования (ограниченно)
* История и закладки не сохраняются между сессиями

## Технологический стек

Python 3.12+, Django 5.2, aiohttp, uvicorn, whitenoise, HTML/CSS/JS.
